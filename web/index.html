ANTES DE DEJARLO ENCENDIDO

Uso, límites y costos.

¿Cuánto tiempo funciona?

Mientras la cuenta AWS y sus recursos estén disponibles y la skill esté habilitada. Cada estudiante debe consultar su saldo y vencimiento con python lab.py doctor. El crédito y la duración pertenecen a cada cuenta.

¿Qué puede responder y cuáles son sus límites?

Explicaciones académicas, definiciones y ejemplos. No consulta Internet en tiempo real ni ejecuta acciones en tus otras aplicaciones. Puede equivocarse.

15 consultas por usuario y hora UTC, 140 tokens de salida, tres pares de historial reciente y vencimiento a los 30 minutos. Si se supera el contador, deja de invocar el modelo, aunque la solicitud a Lambda y el contador siguen siendo operaciones AWS.

¿Cuánto cuesta seguir preguntando?

Ejemplo de 1,000 consultas, con 1,000 tokens de entrada y 140 de salida cada una: Nova Micro, aproximadamente USD 0.055 solo de modelo. Los filtros actuales podrían sumar USD 0.50–1.25, suponiendo 1–4 unidades de entrada y una de salida. Lambda, DynamoDB, registros e impuestos se consideran aparte.

Son escenarios, no una factura garantizada. Precios consultados el 16 de octubre de 2026. Descargar cálculo y fuentes oficiales.

¿Puedo usar una API de OpenAI?

Sí, mediante una adaptación del backend con credenciales propias y nuevas pruebas de latencia. Esa alternativa todavía no está implementada. Pagar OpenAI no renueva AWS ni mantiene encendida una Lambda cuando vence la cuenta. Si el docente exige Bedrock, conserva la ruta probada del proyecto.

¿Cómo la desactivo o elimino?

Temporalmente: Amazon Developer → tu skill → Test → Off. Los recursos AWS permanecen y podrían consumir uso. Decir “para” solo termina esa conversación.

Eliminar el stack CloudFormation de tu laboratorio borra permanentemente su historial, registros y recursos. Guarda primero tus evidencias y confirma cuenta y nombre exactos. Tu código se conserva. Descargar instrucciones de apagado.
